# Beckenburg County campaign-map art

**Approved cartographic map:** [`beckenburg-county-approved.jpg`](beckenburg-county-approved.jpg). This image is the unlabeled, top-down regional base layer for the campaign and level selection. The older `beckenburg-county-base.png` is a superseded reference illustration, **not** the approved selectable-world map.

The game ships the same optimized map image from `assets/runtime/campaign/`. All location dots, names, region descriptions, progression locks, future roads, and discovery effects are **separate runtime UI layers**, not text or symbols painted onto this art.
