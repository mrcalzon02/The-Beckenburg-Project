# Wharf room lighting and distribution

The forecourt plant feeds the two cottages, boathouse, net shed, fish house, and dry undercroft. Street cables run below grade. The pier branches follow supported deck sections around the stair wells. The dry-cell takeoff passes through its roof in a sealed sleeve. None of these service runs requires a change to the player openings, stairs or landings.

The installed circuit checks cover 1,155 duct samples and 66 actual conduit contacts. Each switch is fitted to a real wall. Each fixture is fitted to its own soffit and responds independently. Software and RTX 5070 OpenGL rechecked all eight doors and nineteen routes. The west cottage and undercroft switches also passed separately over live TCP.
