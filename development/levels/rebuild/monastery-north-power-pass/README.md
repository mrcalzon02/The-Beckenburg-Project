# Monastery of Ashen Bells north-range power

Three ceiling fixtures in the archive and three in the vestry now run from separately controlled branches of the main supply. The feeder branches before the east cloister switch and follows the existing masonry. Sealed sleeves carry the feeds through the north-range wall above the door openings.

Software and OpenGL verified all eighteen installed fixtures, thirteen operating doors and eighty-four original route replays. In a live four-player case, an investigator switched off the east cloister, entered the vestry and turned off its lights while the archive stayed lit. The investigator then crossed the existing connecting door to use the archive switch. The case repeated the source restart, ghost breaker trip, reconnect and physical reset checks.

Remaining room distribution, outlying eaves, furnishings and named packaged mission acceptance are open.
