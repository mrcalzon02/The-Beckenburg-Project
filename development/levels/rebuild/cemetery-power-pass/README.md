# Cemetery and Vale Mortuary caretaker power

Each variant uses one screened caretaker plant above the same service yard. The fitted slab and ramp sit on the saved terrain. The canonical generator, cabinet, supported light and service conduit are mounted on that assembly. The local lamp is the connected load in this checkpoint.

The base map and annex each passed the 609 soil measurements and shared runtime movement, door and refuge replays. Software and RTX 5070 show the local light falling to the same ambient baseline when the source stops or the breaker trips. Both four-peer cases walked from the van to the actual controls, tripped the breaker, stopped and restarted the generator, reconnected while still tripped, and reset the board.

Building distribution and individual room switches remain open. The sites also need their case materials, named mission entry and final architecture, art and gameplay review.
