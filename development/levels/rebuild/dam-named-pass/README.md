# Blackwater Dam named dispatch review

The ordinary Windows game archive loads the verified Blackwater geometry, collision, door and room schedules, electrical fittings and water document under the stable WLD-09 campaign entry. Set `-Dbeckenburg.review.blackwaterNative=true` before launching the Java review build to expose the named solo and LAN entries. The default campaign lock remains in effect.

The packaged review uses both game renderers and matches the ventilation checkpoint’s scene, collision and water revisions. The named solo client starts inside the canonical van, crosses to the apron and returns to retreat. A four-player named TCP case crosses three fitted doors in blackout, restores the breaker after a ghost trip, replicates a placed camera to the van and verifies entering, hiding in and leaving the switchgear refuge. All 14 door states were checked again through the package.

The Windows archive was built with `build.cmd package`. The OpenGL and software reviews run with `python tools/verify_blackwater_named.py --gpu` and `python tools/verify_blackwater_named.py`. This review leaves the remaining utilities, full ritual and evidence cases, authored soundscape and story placements, installer and performance acceptance open.
