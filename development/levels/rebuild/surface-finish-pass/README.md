# Native architectural texture set

The same production importer applies wall plaster, masonry, concrete and timber beside worn planks, tile, flagstones, ceiling plaster and matching stair treads. It derives metre-scale coordinates from the visible faces of the built meshes. Existing authored textures, geometry and collision are retained. The finishes load automatically on native maps in both game packages.

The [roster audit](roster.tsv) covers 25 native exports, including the mortuary annex. It verifies textured floors and ceilings on every export and records stair-face coverage by site. The four specialized map renderers keep their existing materials. Native review flags and source-only map availability still follow the mission catalog.

The [Asylum ward](captures/software/asylum-ward-corridor.png) and [Marsh levee](captures/opengl/marsh-levee-stair.png) show the finish at player height. Both packages also repeat the Marsh door, route, rail and full-volume refuge checks. [Package checkpoint](checkpoint.json)
