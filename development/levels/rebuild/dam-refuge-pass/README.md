# Blackwater Dam walk-in refuges

The records office, maintenance workshop, and switchgear room now each have a walk-in cupboard seated on the room’s actual floor. Each protected interior runs 1.58 m across, 1.14 m deep, and 2.02 m high. Protection begins when the player crosses the entrance and ends when the player leaves.

Both game renderers verified the same fitted geometry, 207 usable floor positions, and 2,475 samples across the full interior. The van-to-refuge routes and return paths work in both postures. At zero cover the cupboards remain walkable and the protection cue disappears. Live investigators entered, hid, revealed and exited all three. The host stopped a ghost at the workshop entrance with cover enabled and accepted that same crossing at zero cover.

This is a staged Dam revision. Upstream hydraulics, supported utilities, finish, and named mission acceptance remain open.
