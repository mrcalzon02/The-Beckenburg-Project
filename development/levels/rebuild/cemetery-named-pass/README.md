# Named Cemetery and Vale Mortuary missions

Both variants load the furnished maps through the ordinary solo and LAN site selectors when the review flag is enabled.

```text
-Dbeckenburg.review.cemeteryNative=true
```

The Cemetery retains campaign identity WLD-07 and its existing chapter position. Vale Mortuary is an additive alternative in the review selector. Both packages use the reviewed model, native collision, room schedule and door schedule.

On both maps a solo AI session departed the shared van, returned to its cargo floor and settled retreat. A four-peer session walked continuously from the van through the chapel and the west pavilion, descended the actual stair, and read the memorial register. Named LAN also tested the chapel camera and van monitor, localized EMF, all three rites including refusal from the van, room lighting, breaker recovery, and the walk-in refuges including live entry, concealment, reveal and exit.

Software and RTX 5070 OpenGL used the same native revisions for the room, door, refuge volume, route and light checks. The Windows package ran its audio audit. The Bash copy rules were checked separately against the same eight source hashes.

The maps remain review-gated. Further architecture and material review, complete normal-use furnishings and services, atmosphere, persistence and release acceptance remain open.
