# Blackwater Dam operating thresholds

Fourteen doorways now use the canonical operating leaves. Eight use previously fitted frames. Six older masonry openings received their own indexed casings. A solid return closes the overcut beside the lower gallery’s valve-room jamb.

The switchgear and valve-room guides run square through their actual doorways. Stair guide knots sit on the receiving floors. The door schedule separates upper and lower architectural volumes while keeping their existing gameplay owners.

Software and OpenGL checked all doors in both states, including their swing, standing and crouched movement, sight, object path, aim and acoustic changes. Both ran all 19 owned routes in both directions and both postures. The original tailrace document and canonical van carry forward.

This is a staged gameplay revision. The leaf finish, upstream hydraulics, electrical and water services, full walk-in refuges, and named release integration remain open.
