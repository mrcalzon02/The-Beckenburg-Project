# Drowned Fisherman's Wharf — model requirements

new rough blockout: model planning. No map rebuild is requested by this checklist.

Finish direction: Salt-worn timber, rope, nets and corroded fittings.

## Standard architecture and fixtures

- distinct wall/floor/ceiling kit
- door leaves, frames, hinges and handles
- window frames/glazing/sills
- proper stairs, landings, deck openings and guards
- mounted room lights, switches, breaker and supported service runs
- separate van dock contract; reuse canonical van

## Map-specific models / one-off candidates

- Dock pile/bearer/deck modules — inspect existing assets first.
- boathouse slip cradle — inspect existing assets first.
- suspended net drying frames — inspect existing assets first.
- fish sorting bench and crates — inspect existing assets first.
- dry undercroft tide-line dressing — inspect existing assets first.

- audit existing runtime and owner library
- architecture and route supports

- map-specific landmark machinery/props
- supported clutter
- wear, signage and story detail
- collision, lighting and in-room visual review

No quantities are invented. Audit source dimensions, pivots, UVs, licensing, supports and clearance before reuse. Clean/worn variants are separate assets. Investigator equipment comes from the existing loadout system.
