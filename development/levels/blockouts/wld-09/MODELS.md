# Blackwater Hydroelectric Dam — model requirements

new rough blockout: model planning. No map rebuild is requested by this checklist.

Finish direction: Wet mass concrete, painted machinery and steel.

## Standard architecture and fixtures

- distinct wall/floor/ceiling kit
- door leaves, frames, hinges and handles
- window frames/glazing/sills
- proper stairs, landings, deck openings and guards
- mounted room lights, switches, breaker and supported service runs
- separate van dock contract; reuse canonical van

## Map-specific models / one-off candidates

- Turbine/generator static assembly — inspect existing assets first.
- control desk and mimic panel — inspect existing assets first.
- spillway gate/actuator — inspect existing assets first.
- crest guardrails and maintenance stairs — inspect existing assets first.
- valve manifold and service-gallery pipe supports — inspect existing assets first.
